## The app idea

The app idea I would like to ask to keep free at all costs: a sort of a teacher's aid/grader software, which we could develop, unless there is one already, to help every teacher everywhere not to grade for hours per test.

I imagined this as an open source charity/school funded project, to make it available ultimately for everyone, and to avoid the perils of it being a software for a yearly fee, as it usually now-a-days happens to be.

It would just further increase the price of education in the end, and I think many of us find it horrible. Like there is some kind of knowledge shortage. This would enable every teacher anywhere on the planet to add to, modify it freely, and adapt it to new developments/discoveries at any field of science as needed.

In short, we shall create a framework for a test writing software (and with time so much more than that), which can be loaded to any computer, and then, for the duration of the test, it does not allow students to exit the test, to cheat from the internet, or any other source on the computer. (Teachers/admin password required in case of an accidental restart to continue the test, as it was already started by the user with that name/password once per day.) I don't want to get too deep into the details of security and features for now, but this could connect up easily into the first project I described even, and with A.I. text recognition, and even essays and handwritten exams can check, if one were to take a picture for example of it and feed it to the software. Key phrases, names, dates, equations, solutions, all these can be recognized and marked as correct, so the teacher grading would have an easier time. All this sounds seriously useful to me compared to the costs, especially if we factor in the time we save for the millions of teachers around the globe(s).

It can just be reading essays out loud via text to speech and then voice commands to correct them, add notes or remarks, if none of the A.I. recognition stuff can be applied for some reason.

Tests could be emailed for T.A.s so the Prof. needn't correct them alone. It would (probably) make it harder to cheat as well. (User name/password login, no afterwards modifications.)

Uses no paper! The upside is clear, I think :)

Please let me know if there is such an initiative, if You know about one, and if not, then maybe let's try and create such a thing! I'm sure we can get the necessary funding for this eventually...
