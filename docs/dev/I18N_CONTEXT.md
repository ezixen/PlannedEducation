# Translation Context Guide

This document provides context for each translation key to help translators understand where and how each string is used.

## Key Format: page.element.number
- page: The page or feature area (login, dashboard, exam_editor, etc.)
- element: The UI element type (button, label, title, message, etc.)
- number: Sequential number within the page/element group
