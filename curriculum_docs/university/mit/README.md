# MIT OpenCourseWare — Higher Education Curriculum Reference

## Overview
This directory contains curriculum breakdowns and syllabus references derived from **MIT OpenCourseWare (OCW)**, an initiative of the Massachusetts Institute of Technology (MIT). Through MIT OCW, course materials spanning undergraduate and graduate curricula are openly and freely published to the world.

### Open Access & License Notice
- **Platform**: MIT OpenCourseWare (https://ocw.mit.edu)
- **License**: Creative Commons Attribution-NonCommercial-ShareAlike 4.0 International (CC BY-NC-SA 4.0).
- **Access Model**: MIT OCW is 100% openly accessible without registration, email verification, login credentials, or subscription fees. All course syllabi, assignments, lecture notes, and exam formats can be browsed and downloaded freely.
- **Purpose**: PlannedEducation provides these structured assessment modules and curriculum benchmarks to give university instructors and students high-quality, standardized baseline exams and question banks that adhere to accredited higher-education standards.

## Structure of Course Assessment Modules
PlannedEducation modules mapped from these curriculums are stored under:
`plans/test-modules/modules/university/mit/`

Each module JSON file includes:
1. **Curriculum ID**: `mit-ocw`
2. **Standard Mappings**: Tagged with core academic standards, course codes, and unit competencies.
3. **Question Types**: Multiple choice, long-form derivation/proof essays, and code/algorithm verification questions.
4. **Grading Rubrics**: Clear scoring criteria, partial-credit models, and automated check parameters.
